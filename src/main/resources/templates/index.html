BPM Resolver

Назначение сервиса

Сервис предназначен для работы с мониторингом BPM-процессов: настройки токена доступа, настройки базовых URL, поиска запущенных процессов и их завершения.

Доступные разделы

  • Токен — настройка токена, который используется для доступа к API (ручной ввод или авто-обновление).
  • Базовый URL БПМ — настройка базового URL для запросов к мониторингу процессов.
  • Поиск запущенных процессов — поиск инстансов по фильтрам и массовое завершение выбранных процессов.
