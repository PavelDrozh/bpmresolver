BPM Resolver

Назначение сервиса

Сервис предназначен для работы с мониторингом BPM-процессов: настройки токена доступа, настройки сервиса BPM-плеера, поиска запущенных процессов и их завершения.

Доступные разделы

  • Токен — настройка токена, который используется для доступа к API (ручной ввод или авто-обновление).
  • Настройка BPM-плеера — настройка BPM-плеера для останова процессов.
  • Поиск запущенных процессов — поиск процессов по фильтрам и массовое завершение выбранных процессов.
  • Поиск остановленных процессов — поиск ранее остановленных процессов по фильтрам.
